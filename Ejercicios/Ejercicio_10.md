# Ejercicio 2.10

## ¿Cómo pueden las aerolíneas utilizar la ciencia de datos para mejorar sus ganancias?

Las aerolíneas pueden usar la ciencia de datos para analizar datos sobre sus pasajeros, vuelos y operaciones. Esto les permite conocer mejor la demanda de vuelos y tomar decisiones sobre sus servicios, precios y horarios.

También pueden usar estos datos para mejorar la planificación de vuelos, reducir costos, usar mejor sus recursos y ofrecer servicios de acuerdo con las necesidades de los pasajeros. De esta manera, pueden aumentar sus ganancias y mantener a sus clientes satisfechos.
