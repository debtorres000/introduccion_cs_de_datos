# Ejercicio 2.1

**Pregunta:** ¿Cómo puede ser útil la ciencia de datos en los servicios de salud?

**Respuesta:** La ciencia de datos permite analizar información médica para:

- Detectar enfermedades de forma temprana.
- Monitorear pacientes.
- Predecir posibles problemas de salud.
- Mejorar el uso de recursos en hospitales.
- Ayudar a mejorar los tratamientos.
