# Ejercicio 2.8: Ciencia de datos en la Industria 4.0

Con IoT, robótica y sensores inteligentes, la ciencia de datos optimiza la producción y reduce costos.

- **Mantenimiento predictivo:** anticipa fallas de maquinaria.
- **Análisis de rendimiento:** pronostica el desempeño antes de producir.
- **Menos tiempo de inactividad:** menos paros en fábrica.
- **Optimización de activos:** define cuándo y cuánto usar cada recurso.
- **Diseño de producto:** predice si un diseño tendrá éxito.
- **Pronóstico de demanda:** anticipa el mercado.
- **Cadena de suministro:** elige a los proveedores más eficientes.

**Idea clave:** decidir con datos antes de que ocurra el problema.
